# .ai_claude — 学习 OpenClaw 的上下文存档

这个目录由 Claude 维护，用于在多次会话之间保留学习 OpenClaw 源码的上下文。
未来任何一次会话开始时，Claude 应先读这里的 `README.md` 和 `progress.md`。

## 用户背景

- 用户是一名程序员（中文母语），fork 了 openclaw 项目，目的是学习其源码以便更好地使用它。
- 当前在 `study-base-v2026.4.26` 分支上学习，会在源码里加 `// lyc:ai` / `// lyc:` 形式的中文注释作为学习笔记。
- 倾向于 **入口追踪法**（从 `npm run dev` 一路读下去）。

## 文件索引

- `README.md` — 本文件，总览 + 索引
- `progress.md` — 用户的阅读进度轨迹（必读，会持续更新）
- `learning-map.md` — OpenClaw 代码库的"产品代码 vs 脚手架"地图，以及推荐的阅读顺序

## 给未来 Claude 会话的提示

1. **首次进入对话时**：读 `progress.md` 了解用户已经看到哪里，避免重复讲解。
2. **用户继续追踪某个文件时**：检查 `progress.md` 的"调用栈"小节，看是否已记录上下文。
3. **用户停下来问问题时**：基于 `learning-map.md` 给出"这部分在整体里属于什么"的定位回答。
4. **完成一次有意义的阅读**（读完一个文件 / 理解一个模块）后，**更新 `progress.md`**。
5. **绝对不要假装记得"上次"——** 始终以这个目录里的内容为唯一事实来源。

## 与全局 memory 系统的关系

- 全局 memory（`~/.claude/projects/.../memory/`）保留**跨项目**的用户偏好。
- 本目录保留**这个项目**的学习状态——文件路径、调用关系、未解之谜，这些不该污染全局 memory。
